# SNAKE: PIXEL RUSH

یک بازی آرکید پیکسلی، کاملاً آفلاین و چندجهانه روی **HTML5 Canvas + ماژول‌های JS** که هم به‌صورت فایل مستقل HTML اجرا می‌شود و هم درون پوسته اندرویدی **Jetpack Compose + WebView** (`MainActivity.kt` / `GameBridge.kt`) بسته‌بندی شده است.

---

## ویژگی‌های کلیدی گیم‌پلی
- **۵ حالت بازی:** رکوردزنی، زمان‌سنج ۶۰ث، مراحل (پازل و باس)، شکار باس، و سیاهچال تکاملی (Roguelite)
- **۶ جهان متفاوت:** جنگل، آتشفشان، یخبندان، صحرا، شب نئونی، و دژ دیجیتال با مکانیک‌ها و تله‌های اختصاصی
- **کمبوی بحرانی:** `×2` (امتیاز دوبرابر)، `×3` (جاذبه غذا)، `×5` (حالت جنون + هاله زمین و انرژی اضافه) و `×10` (حالت طلایی + سکه اضافه روی هر سیب)
- **۵ رلیک دائمی در Run:** دندان طلایی، چشم شبح، ساعت شکسته، پولک اژدها (نجات از مرگ) و هسته مغناطیس
- **اتاق‌های مخفی:** ورودی پنهان در جهان‌ها به ۳ نوع اتاق مخفی (گنج، نگهبان، خزانه ۱۵ث) بدون از دست رفتن وضعیت بازی اصلی
- **شبح رقیب (Rival Ghost):** مسابقه زنده با شبح بهترین رکورد ثبت‌شده در هر ترکیب جهان/حالت و جایزه سبقت
- **تکامل ظاهری (Evo Forms):** ۵ فرم بصری قابل انتخاب در تب «تکامل» متناسب با سطح بازیکن (`LV 1/5/10/15/20`)
- **ژن‌ها و ترکیب ۲تایی + بازگشت زمان:** ۳ مهارت پایه، ۸ ژن قابل ترکیب، دش و بازگشت زمان با پیش‌نمایش
- **اقتصاد آفلاین و منصفانه:** تک‌جایگاه صندوق (برنزی ۵د، نقره‌ای ۱۰د، طلایی ۲۰د)، مأموریت‌های روزانه/هفتگی/مخفی، و پشتیبان‌گیری متنی

## معماری منبع واحد (Single Source of Truth)
منبع اصلی کدها در فایل `template.html` و ماژول‌های `js/*.js` قرار دارد و تمام نسخه‌های نهایی از همین منبع تولید می‌شوند تا هیچ‌وقت بین HTML و فایل داخل APK اختلاف ایجاد نشود:

1. `js/storage.js` — ذخیره و بارگذاری (`localStorage` + پل `AndroidBridge`)، مهاجرت و کد پشتیبان
2. `js/audio.js` — موتور صدای پیکسلی Web Audio API و لرزش
3. `js/snake.js` — ماتریس‌های پیکسلی ۲۰×۲۰ و رندر مار پیوسته همراه با تکامل ظاهری و هاله طلایی
4. `js/worlds.js` — چیدمان ۵ حالت / ۶ جهان با تضمین مسیرباز (BFS) + ژنراتور اتاق‌های مخفی
5. `js/enemies.js` — هوش مصنوعی مارهای شکارچی/رقیب/نگهبان و باس‌های ۳فازه
6. `js/modes.js` — جدول حالت‌های بازی، دسته‌بندی قوانین و بذر روزانه
7. `js/progression.js` — صندوق‌ها، ژن‌ها، رلیک‌ها، فرم‌های تکامل، رویدادهای آرکید، دستاوردها و مأموریت‌ها
8. `js/renderer.js` — رندر Canvas، نورپردازی جنون/طلایی، شبح رقیب، چشم شبح و مینی‌پریویو
9. `js/core.js` — حلقه بازی، برخورد، کمبوی بحرانی، اتاق مخفی، رلیک‌ها، بازپخش و شبح رقیب
10. `js/ui.js` — رابط کاربری ۵ تبه، فروشگاه، تکامل بصری، مودال‌ها و تنظیمات

## ساخت و همگام‌سازی خودکار
برای تولید هم‌زمان و یکسان هر سه خروجی HTML (`snake_clash_royal.html`، `app/src/main/assets/snake.html` و `public/assets/aistudio/snake_d90c69e2.html`) به همراه بررسی نحو، عدم وجود ایموجی، تطابق IDهای DOM و آیکون‌های پیکسلی:

```bash
python3 scripts/build_game.py
```

---

## ساخت و تست اندروید (AI Studio / Gradle)
- **اجرای تست‌های واحد و Robolectric:**
  ```bash
  gradle :app:testDebugUnitTest
  ```
- **ساخت APK دیباگ:**
  ```bash
  gradle :app:assembleDebug
  ```
> **نکته کلیدی درباره Keystore و Gradle Wrapper:** در این محیط، کلیدهای امضا (`debug.keystore`) و تنظیمات ساینینگ در `app/build.gradle.kts` به‌صورت خودکار توسط زیرساخت AI Studio مدیریت می‌شوند؛ بنابراین فایل‌های keystore و `gradlew` داخل مخزن دستی ساخته یا تغییر داده نمی‌شوند و اجرای دستورات از طریق `gradle` سیستم انجام می‌شود.
