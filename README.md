# SNAKE: MAZE ROYALE

یک بازی آرکید-هزارتوی پیکسلی، کاملاً آفلاین و چندآرنایی روی **HTML5 Canvas + ماژول‌های JS** که هم به‌صورت فایل مستقل HTML اجرا می‌شود و هم درون پوسته اندرویدی **Jetpack Compose + WebView** (`MainActivity.kt` / `GameBridge.kt`) بسته‌بندی شده است.

---

## ویژگی‌های کلیدی گیم‌پلی
- **۵ حالت بازی:** رکوردزنی، حمله زمانی، مرحله‌ای (معمای کلید و باس)، نبرد باس و سیاهچال تکاملی (Roguelite)
- **۶ آرنای رتبه‌بندی‌شده:** جنگل سبز، غار مذاب، قلمرو یخ، جهان سایه، بیابان طلایی و دژ دیجیتال همراه با رتبه‌های برنز، نقره و طلا و کاپ آرنا
- **موتور هزارتو (Maze Engine):** مه هزارتوی قابل‌تغییر (Fog of War)، ۲ دیوار مخفی شکننده با دش، معمای کلیدهای شماره‌دار (۱ و ۲) و قطعات نقشه (جمع‌آوری ۳ قطعه تمام مه نقشه را باز می‌کند)
- **دک ۳ کارت تاکتیکی (بدون Pay-to-Win):** ۸ کارت تاکتیکی قابل ارتقا از سطح ۱ تا ۳ با طلای داخل بازی و تأثیر مستقیم روی دش، مهارت، مغناطیس و حفاظت
- **کمبوی بحرانی:** `×2` (امتیاز دوبرابر)، `×3` (جاذبه غذا)، `×5` (حالت جنون + هاله زمین و انرژی اضافه) و `×10` (حالت طلایی + سکه اضافه روی هر سیب)
- **۵ رلیک دائمی در Run:** دندان طلایی، چشم شبح، ساعت شکسته، پولک اژدها (نجات از مرگ) و هسته مغناطیس
- **۶ نوع اتاق مخفی:** گنج، نگهبان، خزانه ۱۵ث، محراب رلیک، فروشگاه بین‌راهی و باس مخفی بدون از دست رفتن نقشه اصلی
- **شبح رقیب (Rival Ghost):** نمونه‌برداری یکنواخت از فریم صفر (`downsampleFrames`) و مسابقه هماهنگ از ثانیه اول تا پایان دست
- **بهینه‌سازی و پایداری:** ذخیره اضطراری حین بازی در خروج ناگهانی + محدودسازی خودکار افکت‌ها (`MAX_PARTICLES` / `perfLowMode`)

## معماری منبع واحد (Single Source of Truth)
منبع اصلی کدها در فایل `template.html` و ماژول‌های `js/*.js` قرار دارد و تمام نسخه‌های نهایی از همین منبع تولید می‌شوند:

1. `js/storage.js` — ذخیره و بارگذاری (`localStorage` + پل `AndroidBridge`)، مهاجرت و کد پشتیبان
2. `js/audio.js` — موتور صدای پیکسلی Web Audio API و لرزش
3. `js/snake.js` — ماتریس‌های پیکسلی ۲۰×۲۰ و رندر مار پیوسته همراه با تکامل ظاهری و هاله طلایی
4. `js/worlds.js` — ۶ آرنا با تضمین مسیرباز (BFS)، دیوارهای مخفی، کلیدهای معما و ۶ نوع اتاق مخفی
5. `js/enemies.js` — هوش مصنوعی مارهای شکارچی/رقیب/نگهبان و باس‌های ۳فازه
6. `js/modes.js` — جدول حالت‌های بازی، رکورد آرناها و مراحل معمایی-سرعتی
7. `js/progression.js` — صندوق‌ها، دک ۸ کارت تاکتیکی (سطح ۱–۳)، رتبه آرناها، ژن‌ها، رلیک‌ها و مأموریت‌ها
8. `js/renderer.js` — رندر Canvas، مه هزارتو، دیوارهای مخفی، کلیدهای معما، شبح رقیب و بهینه‌ساز افت فریم
9. `js/core.js` — حلقه بازی، برخورد، کمبوی بحرانی، مه و قطعات نقشه، شبح رقیب یکنواخت و ذخیره اضطراری
10. `js/ui.js` — رابط کاربری ۵ تبه (بازی، آرناها، کارت‌ها، تکامل، گنجینه)، ارتقای کارت‌ها و بازیابی دست ناتمام

## ساخت، همگام‌سازی و تست مکانیک‌ها
برای تولید هم‌زمان و یکسان هر سه خروجی HTML (`snake_clash_royal.html`، `app/src/main/assets/snake.html` و `public/assets/aistudio/snake_d90c69e2.html`) و اجرای تست مکانیک‌ها:

```bash
python3 scripts/build_game.py
node scripts/test_mechanics.js
```
