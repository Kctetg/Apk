# SNAKE: PIXEL RUSH — جنگل پیکسلی

یک بازی پازل-هزارتوی پیکسلی با نمای کلاسیک از بالا روی **HTML5 Canvas + ماژول‌های JS** و پوسته اندرویدی **Jetpack Compose + WebView**؛ با تمرکز کامل بر وضوح، یادگیری سریع و کشف مسیرهای مخفی:

**یک مار، یک نقشه (جنگل پیکسلی)، یک هدف واضح، یک خطر اصلی و یک خروجی سبز.**

---

## طراحی ساده و متمرکز گیم‌پلی
- **چرخه واضح مراحل:**
  - مراحل ۱ تا ۳ به‌صورت گام‌به‌گام حرکت و سیب قرمز، دیوارهای سنگی، و کلید زرد + در سبز را آموزش می‌دهند.
  - از مرحله ۴ به بعد **مسیرهای مخفی خزه‌ای** با سنگ معما روی زمین معرفی می‌شوند که کریستال و پاداش پنهان را باز می‌کنند.
  - هر ۵ مرحله یک **مرحله ویژه** قرار دارد: هزارتوی ویژه با مار نگهبان (مراحل ۵، ۱۵...) یا نبرد قابل یادگیری با اژدهای جنگل (مراحل ۱۰، ۲۰...).
- **قانون رنگ‌ها:** سیب همیشه **قرمز**، کلید همیشه **زرد** و دروازه خروجی پس از تکمیل هدف همیشه **سبز** است.
- **رابط کاربری خلوت:**
  - داخل بازی فقط **شماره مرحله، امتیاز، هدف یک‌جمله‌ای، نقشه جنگل، کنترل حرکت و مکث** نمایش داده می‌شود.
  - منوی ۳ تب ساده: **مرحله‌ها**، **ظاهر مار** (اسکین‌ها با پیشرفت مراحل باز می‌شوند) و **رکوردها** (بهترین امتیاز، سریع‌ترین زمان، مراحل بدون برخورد و مسیرهای مخفی).
